# Prayer Times App

A simple prayer times web application built while learning and practicing JavaScript and working with external APIs.

The app allows users to select a country and city and displays the prayer times for the selected location.

## Features

* Select a country and city
* Displays prayer times for the selected location
* Shows Gregorian and Hijri dates
* Supports Palestine, Jordan, Egypt, and Saudi Arabia
* City options change based on the selected country
* Loading message while fetching data
* Displays an error message if the request fails
* Responsive design
* Arabic interface

## Technologies

* HTML
* CSS
* JavaScript
* Fetch API
* AlAdhan Prayer Times API
